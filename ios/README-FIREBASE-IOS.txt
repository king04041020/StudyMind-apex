Configuration Firebase iOS :
1. Télécharger GoogleService-Info.plist depuis les paramètres Firebase du projet StudyMind.
2. Placer ce fichier dans ios/Runner/GoogleService-Info.plist.
3. Vérifier que le fichier est inclus dans la cible Runner dans Xcode.
Le fichier n'est pas inclus dans cette archive car il doit provenir de ton projet Firebase.
